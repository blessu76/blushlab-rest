Pendant la création de notre jeu de maquillage, nous avons utilisé le nom provisoire glowroom. Une app iOS porte déjà ce nom, nous l'avons donc abandonné. Le nom Blushlab a été confirmé le 2026-11-19.

En coréen, le jeu s'appelle 블러쉬랩. Dans toutes les autres langues, il reste Blushlab.

## Questions fréquentes

### Quel était l'ancien nom provisoire ?

glowroom. Nous ne l'utilisons plus car une app iOS porte déjà ce nom.

### Comment le nom s'écrit-il en coréen ?

블러쉬랩. Les autres langues utilisent Blushlab.

### Blushlab est-il déjà sorti ?

Pas encore. Le jeu est en développement pour iOS et Android, sans page de store ni date de sortie pour l'instant.
