While building our makeup game we used the working name glowroom. An iOS app with the same name already exists, so we dropped it. The name Blushlab was confirmed on 2026-11-19.

In Korean the game is called 블러쉬랩. In every other language it stays Blushlab.

## FAQ

### What was the old working name?

glowroom. We no longer use it because an iOS app with that name already exists.

### How is the name written in Korean?

블러쉬랩. Other languages use Blushlab.

### Is Blushlab out yet?

Not yet. It is in development for iOS and Android, and there is no store page or release date.
