Blushlab tidak memiliki iklan. Kami ingin waktumu bersama game ini dipakai untuk makeup, bukan untuk menutup pop-up.

Game ini masih dalam pengembangan, jadi kami akan berbagi lebih banyak seiring perkembangannya.

## Pertanyaan umum

### Apakah game ini menampilkan iklan?

Tidak. Blushlab tidak memiliki iklan.

### Di mana saya bisa mengikuti perkembangannya?

Di jurnal ini. Kami menulis kabar terbaru seiring game ini terbentuk.

### Apakah Blushlab sudah dirilis?

Belum. Game ini sedang dikembangkan untuk iOS dan Android, dan belum ada halaman toko maupun tanggal rilis.
